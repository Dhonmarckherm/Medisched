# Medisched

A modern medical scheduling application built with Next.js and TypeScript.

## 🚀 Live Demo
[View Live](https://medisched-cert.vercel.app)

## 📋 Overview
Medisched is a medical appointment scheduling platform that helps patients and healthcare providers manage bookings, appointments, and medical records efficiently.

## ✨ Features
- **Appointment Scheduling** — Book and manage medical appointments
- **Dashboard** — Overview of upcoming appointments and recent activity
- **User Authentication** — Secure login and registration
- **Responsive Design** — Works on desktop, tablet, and mobile
- **Real-time Updates** — Instant notifications for appointment changes

## 🛠️ Tech Stack
- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Database:** Supabase (PostgreSQL)
- **Deployment:** Vercel
